# 자동충전 단자 — 마그네틱 포고핀

도킹 충전을 자동화하기 위해 기본 충전 커넥터를 마그네틱 포고핀으로 교체했습니다.
로봇이 ±2mm 정밀 도킹으로 후진 진입하면 자석이 단자를 끌어당겨 결합됩니다.

## 구성

- 마그네틱 도킹 커넥터 4핀 (암/수), 2A / 12V
- 상세 사양: 판매사 데이터시트 참조 (팀 저장소 hardware/charging_pogo)

## 개발 중 잡은 문제들

- **연결 직후 전선 소손** — 충전기에 연결하자마자 타버림. 추적 결과 기존 배선이
  사양과 달리 27AWG로 얇았던 것이 원인. 22AWG로 교체 후 정상 충전 확인.
- **결합 방향 오류** — 충전이 안 되는 원인을 대조군(정상 동작 로봇)으로 분리해
  단자 결합 방향 문제로 규명.

## 검증

- 충전 판정은 타이머가 아니라 실제 배터리 +3%p 상승 관측으로 확정 (소프트웨어 정책과 연동)
- 1·2호기 자동 교대 사이클에서 반복 검증
